## English

Travelista is a travel guide website that presents countries with full-screen videos, city highlights, sights, local food and practical travel tips. The whole site is available in Turkish, English and German.

### Features

- More than 50 countries grouped by continent
- Three languages (TR / EN / DE) with a language switcher
- Site-wide search across countries, cities and topics
- Country pages with hero video, photo gallery and travel tips
- Responsive layout for phone, tablet and desktop
- Content kept in separate files, so texts can be edited without touching the components

### Built with

React · TypeScript · Vite · React Router · three.js · CSS

### Run locally

```sh
npm install
npm run dev
```

Then open http://localhost:3000.

## Deutsch

Travelista ist eine Reise-Website, die Länder mit bildschirmfüllenden Videos, Städten, Sehenswürdigkeiten, lokaler Küche und praktischen Reisetipps vorstellt. Die gesamte Seite ist auf Türkisch, Englisch und Deutsch verfügbar.

### Funktionen

- Über 50 Länder, nach Kontinenten geordnet
- Drei Sprachen (TR / EN / DE) mit Sprachumschalter
- Seitenweite Suche nach Ländern, Städten und Themen
- Länderseiten mit Hero-Video, Fotogalerie und Reisetipps
- Responsives Layout für Smartphone, Tablet und Desktop
- Inhalte liegen in eigenen Dateien und lassen sich ohne Änderungen an den Komponenten bearbeiten

### Technologien

React · TypeScript · Vite · React Router · three.js · CSS

### Lokal starten

```sh
npm install
npm run dev
```

Danach http://localhost:3000 öffnen.

## Türkçe

Travelista; ülkeleri tam ekran videolar, şehirler, gezilecek yerler, yerel lezzetler ve seyahat ipuçlarıyla tanıtan bir seyahat rehberi sitesidir. Sitenin tamamı Türkçe, İngilizce ve Almanca olarak kullanılabilir.

### Özellikler

- Kıtalara göre gruplanmış 50'den fazla ülke

- Ülke, şehir ve konularda site içi arama
- Hero videosu, fotoğraf galerisi ve seyahat ipuçları içeren ülke sayfaları
- Telefon, tablet ve masaüstüne uyumlu tasarım
- İçerikler ayrı dosyalarda tutulur; bileşenlere dokunmadan metin düzenlenebilir

### Kullanılan teknolojiler

React · TypeScript · Vite · React Router · three.js · CSS

### Bilgisayarda çalıştırma

```sh
npm install
npm run dev
```

Ardından http://localhost:3000 adresini açın. İçerik düzenleme rehberi: [`src/content/README.md`](src/content/README.md)
